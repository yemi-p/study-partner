8.3 Set-builder notation

A = {integer x : x < 4} is short for ‘A is the set
of integers, x, such that x is less than 4’. This is an
example of set-builder notation. In set-builder
notation, the colon (:) stands for ‘such that’. If
set-builder notation is expressed properly, it is
always possible to list the elements of the given
set. For example, in this case

A = {...,-2, -1,0, 1,2, 3}
Notice that the elements of A are restricted to
integral or whole-number values. The letter Z,
sometimes written Z, is often reserved for the set
of integers:

= (55, =3, —2, -1, 0,41, +2¢3;503}
Hence set A can be rewritten
=(x:x<4,xeEZ}

i.e. ‘A is the set of values of x such that x is less
than 4, where x is an integer’.

If, however, the elements of A are restricted to
natural numbers, i.e. positive whole-numbers, then

A = {1,2,3}

reserved for the set of natural numbers:
